# windows-server-active-directory-lab
Windows Server and Active Directory administration – hands-on learning and homelab documentation.
Windows Server & Active Directory Lab

Project Overview

This project is dedicated to learning Windows Server administration, Active Directory, networking, PowerShell, and enterprise IT infrastructure through practical hands-on experience in a personal homelab.

The project follows a structured, step-by-step learning approach, starting with fundamental concepts and progressing towards advanced system administration.

Project Objectives

- Install and configure Windows Server.
- Understand Windows Server networking.
- Deploy and manage Active Directory Domain Services.
- Build a functional domain environment.
- Join Windows computers to the domain.
- Manage users, computers, groups, and organisational units.
- Configure DNS and DHCP services.
- Create and manage Group Policy Objects.
- Manage file servers and access permissions.
- Develop PowerShell administration and automation skills.
- Implement security best practices.
- Learn backup and disaster recovery procedures.
- Develop practical troubleshooting skills.
- Create professional technical documentation.

Learning Methodology

The project combines theoretical knowledge with practical laboratory exercises.

Where technically possible and safe, administrative tasks will be performed using two different methods:

- Graphical User Interface (GUI).
- PowerShell command-line administration.

Each exercise will include:

- Learning objectives.
- Theoretical background.
- Practical configuration.
- Command explanations.
- Configuration verification.
- Troubleshooting.
- Technical documentation.

Progression to the next task requires successful verification and confirmation that the current topic is understood.

Security

All configuration changes will be carefully planned and verified to minimise disruption to existing homelab services.

Sensitive information, passwords, authentication tokens and private keys must never be committed to this repository.

Potentially disruptive configurations will be tested in an isolated environment before implementation.
